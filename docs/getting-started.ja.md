# ソースから試す・入門ガイド

[KindleToZipの紹介へ戻る](../README.ja.md)

## 現在の提供状況

**[Windows x64用Portable v0.1.2](https://github.com/zufall-upon/KindleToZip/releases/tag/v0.1.2)は2026-10-28から一般公開中で、Latestに掲載しています。** 必須のソース検査・配布版の自作試料検査は成功済みです。**2026-10-29**に、クリーンWindowsでの動作と実書籍全冊の取得も利用者側で確認済みとの報告を受け、利用者の指定で実験版表記を外しました。[検証履歴](validation.md)では利用者の報告と自動検査を区別し、過去の失敗も別に残しています。

開発環境なしで使う場合は[Portableガイド](portable.md)に従い、リリースZIPをハッシュ照合後に全体展開して `KindleToZip-Portable.exe` を起動してください。以下は**ソース実行専用の手順**です。ソースの導入や自作試料の利用にAmazonの認証情報は不要です。

## 必要な環境

- Windows x64と、書き込み可能なローカルのプロジェクトフォルダ。
- Git・**Node.js 22以降**・**PowerShell 7**（`pwsh`）。以下はWindows PowerShell 5.1ではなくPowerShell 7で実行します。
- ツール・依存物を初回取得するためのインターネット接続。
- スクリプトは専用の **Rust 1.99.1** を隔離して導入し、**Playwright 1.64.1 / Chromium revision 1248** を使用します。通常のブラウザプロファイルや、グローバルのRust PATHは変更しません。

ソース実行と異なり、Portable版のパッケージ作成には **Node.js 22.14.0** が必要です。[開発用ビルド手順](development.md)（英語）を参照してください。

## 導入と起動

各コマンドを順番に実行し、失敗したら止めてください。チェックサム不一致・ビルド失敗・テスト失敗を無視して先へ進めないでください。インストーラーはコントローラーの依存物を取得するため、続けてランチャーの依存物を明示取得します。既存スクリプトの使い方の説明であり、スクリプトの動作変更ではありません。

```powershell
git clone https://github.com/zufall-upon/KindleToZip.git
cd KindleToZip
npm ci --ignore-scripts --no-fund --no-audit
./scripts/install-rust.ps1 -FetchDependencies
& ./artifacts/toolchains/cargo/bin/cargo.exe fetch --manifest-path poc/launcher/Cargo.toml --locked
node scripts/install-browser.mjs
node scripts/install-browser.mjs --headed
pwsh -NoProfile -File scripts/test-rust.ps1
npm start
```

Rustインストーラーと直後の `cargo fetch` は同じPowerShellセッションで行い、専用環境の設定を引き継ぎます。Windowsの実行ポリシーでスクリプトが止まる場合は、内容と組織のポリシーを確認し、セキュリティ設定を全体で無効にしないでください。

専用ブラウザのウィンドウにローカル操作画面が開きます。画面を閉じるか、起動したターミナルでCtrl+Cを押すと通常終了します。コントローラーのEXEが使用中なら、上書きビルドや無関係なプロセスの終了はせず、自分のアプリを通常終了してから再ビルドするか、別のソース配置を使ってください。

## 実書籍なしで試す

1. **「決定・次へ」** で新しい作業を用意します。
2. 専用セッション・自作試料の補助設定を開き、**自作試料**を選びます。
3. 試料の読書タブを選び、プレビューを確認してチェックし、承認します。**承認だけでは取得しません。**
4. 別の操作で明示開始し、停止後に保存画像を点検してから出力します。

試料は自作の図形と文字です。成功しても、現在のKindle・全レイアウト・全冊取得への対応を証明するものではありません。ログイン画面を取得対象にしないでください。

## Kindle Webで使う

1. アプリから専用Kindleブラウザを開きます。本人が**公式画面で**ログイン・追加認証を行い、1冊を開いて開始位置を調整します。
2. アプリへ戻り、本棚ではなく実際の読書タブを選びます。現在の入口は日本向けKindle Webです。対応するKindleプリセットを試し、必要なら取得領域・本の識別・位置・次へボタンを手動指定します。
3. プレビューの本・範囲・方向・位置を確認します。承認後、別の操作で明示開始します。対象不明・認証状態の変化・送りの不確実性などで停止する場合があります。
4. 停止後に画像の採用・除外・順序・クロップ・任意の見開き分割を点検します。取得やプレビューの停止後も確定保存画像は出力できます。アーカイブの検証成功は全冊取得を意味しません。

主操作は **「決定・次へ」「キャンセル・前へ」「終了・最初から」** です。画面の次操作に従ってください。3工程は、3クリックで完了するという意味ではありません。言語メニューで日本語・英語・簡体字中国語を選べます。現在のソースCIでは公開言語切り替え検査も成功しており、過去の失敗と配布版検査の範囲は[検証記録](validation.md)で区別しています。

## 画像・保存データ・プライバシー

最新ソースでは取得前に「取得画像の形式」とJPEG画質（1〜100）を選べます。JPEGは取得時に圧縮され、クロップ・分割でも再圧縮されるため、画質と容量をプレビュー・点検して選んでください。取得済み原本のバイトは変更しません。点検画面で画像ごとに1枚／2枚と読み順を修正し、余白を手動クロップできます。「全原寸へ戻す」は原本を使い直します。自動余白カットはしません。判定・写り込み対策は完全ではないため、出力前に本人が確認してください。これらの追加機能は公開済みv0.1.2には含まれません。

- 標準・2倍の描画密度は表示の描き方を変えるもので、元にない細部を復元しません。画像ごとの **16メガピクセル・32 MiB** は安全上の上限であり、有料の制限ではありません。
- 見開き分割は任意です。右→左・左→右を選び、結果を点検してください。内容を意味的に認識する機能ではありません。除外・クロップでも原本を保持し、既存の出力は上書きしません。
- 開発版の作業データ・専用プロファイルは、別のローカル作業先を明示指定しない限り `artifacts/mvp-data/` に置きます。PortableビルドはEXE横に `runtime/`・`data/`・`temp/` を作成します。
- **ログイン状態の保存は既定ONです。** OFFでは別の一時プロファイルを作り、通常終了で削除しますが、異常終了時は残る場合があります。保存済みプロファイルは同じPC・Windows利用者での再利用が前提で、Amazonの失効・再認証要求は回避しません。
- Cookie・プロファイル・書名・画像・出力アーカイブは非公開で扱い、フォルダを公開の不具合報告に添付しないでください。安全消去や、管理者・同じWindows利用者からの秘密保持は保証しません。
- 公式の読書・認証通信と初回取得はネットワークが必要です。アプリ独自のテレメトリ・自動更新確認・支援ページへの自動アクセスはありませんが、公式サービスやChromiumによる追加通信はあり得ます。オフライン動作・通信隔離の保証ではありません。

[セキュリティと通信の詳細](security-and-trust.md)（英語）、[検証記録](validation.md)（英語）、[法的注意事項](legal-notes-ja.md)を参照してください。DRMを解除しなくても、Amazon規約や著作権への適合は証明されません。非公式アプリであり、GPLv3は書籍内容の再配布を許諾しません。

## うまく動かないとき

不明な対象や黒いプレビューで開始を繰り返さず、停止して既存画像を保持し、画面の次操作に従ってください。[既知の検証失敗](validation.md)（英語）を先に確認してください。文書で不具合が直るわけではありません。報告には認証情報・書名・書籍本文・個人パスを含めないでください。

ソースのテスト・Portable版の作成・ビルド証明は[開発手順](development.md)と[リリース検証](releasing.md)（英語）へ。開発者向けの手順であり、現在入手できる一般向け実行ファイルや、リリース合格を示すものではありません。
