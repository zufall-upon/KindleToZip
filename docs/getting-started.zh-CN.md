# 从源代码开始 · 入门指南

[返回 KindleToZip 简介](../README.zh-CN.md)

## 目前提供什么？

[Windows x64 Portable v0.1.6](https://github.com/zufall-upon/KindleToZip/releases/tag/v0.1.6) 自 **2026-10-29** 起以普通Release＋Latest公开。必需的源代码与打包版本自制样本检查已通过。用户已确认本地图像改进；此前干净Windows与真实书籍完整获取报告针对v0.1.2，并非本次托管EXE的结果。[验证历史](validation.md)区分用户报告与自动检查，并保留早期失败。

无需开发环境的用法见 [Portable 指南](portable.md)：下载发布 ZIP、校验哈希、完整解压，再运行 `KindleToZip-Portable.exe`。以下仅为**从源代码运行的步骤**。安装源代码和使用自制样本不需要 Amazon 登录信息。

## 环境要求

<a id="ubuntu-source"></a>
### Ubuntu 实验性源码版（复用现有环境）

`linux-port` 仅用于自制样本。真实 Kindle、常规 Wayland 阅读与 Linux 分发仍未支持／未验证。先检查容量和挂载，复用现有 Node 22、Rust 1.99.1 控制器和固定 Playwright/Chromium 环境；不要在 Ubuntu 执行下方 Windows 安装器。命令与限制见 [Ubuntu 开发路径](development.md#experimental-ubuntu-source-development)（英语）。

控制窗口有界面，样本阅读器默认 headless。在 Wayland 会话中显式运行 `npm start -- --sample-headed`，创建作业后可通过辅助浏览器操作中的专用有头按钮打开应用生成的标准自制样本。依次选择标签页、预览、确认并单独开始。使用新临时配置文件，不接受任意 URL、其他样本或已保存配置文件。检查仅限自有浏览器目标和保存数据，不证明整个系统画面不被遮挡，也不保证不干扰其他应用或物理输入。真实 Kindle 仍不支持。Linux 可选用可执行的 `/usr/bin/zenity` 选择 ZIP/CBZ 保存位置；选择或取消不会保存、获取，导出需要另外明确操作且不覆盖文件。缺失或失败时仍可手动输入，不会自动安装。桌面／portal 行为需要按环境验证。

在 Ubuntu 26.04 中，已通过本人操作，使用已安装的 Zenity 验证匿名 ZIP/CBZ 保存位置选择与取消，并收到显示正常的本人目视报告。原生对话框图像未提供，也未独立检查。这些检查确认仅选择位置不会导出文件；ZIP/CBZ 输出与内容核对是另行进行的集成检查，不代表原生选择器导出或真实 Kindle 已验收。

启动诊断区分已知的控制器、私有目录、锁与控制窗口失败，不会自动修复权限或下载依赖。怀疑 `TMPDIR` 过长时，请通过 `KTZ_TEMP_DIR` 明确指定较短的私有目录；不会自动转移，也不按猜测的长度阈值拒绝。

### Windows x64

- Windows x64，以及可写的本地项目目录。
- Git、**Node.js 22 或更高版本**、**PowerShell 7**（`pwsh`）。以下命令需要 PowerShell 7，而不是 Windows PowerShell 5.1。
- 首次下载工具与依赖时需要互联网连接。
- 脚本安装隔离的 **Rust 1.99.1**，使用 **Playwright 1.64.1 / Chromium revision 1248**，不会替换日常浏览器配置目录，也不会修改全局 Rust PATH。

与源代码运行不同，Portable 打包必须使用 **Node.js 22.14.0**。请参阅[开发构建说明](development.md)（英语）。

## 安装并启动

按顺序逐条运行命令，失败时停止。不要忽略校验和不符、构建失败或测试失败。安装脚本只获取控制器依赖，因此下一条命令明确获取启动器依赖。这是在说明现有脚本的使用方式，不是修改脚本行为。

```powershell
git clone https://github.com/zufall-upon/KindleToZip.git
cd KindleToZip
npm ci --ignore-scripts --no-fund --no-audit
./scripts/install-rust.ps1 -FetchDependencies
& ./artifacts/toolchains/cargo/bin/cargo.exe fetch --manifest-path poc/launcher/Cargo.toml --locked
node scripts/install-browser.mjs
node scripts/install-browser.mjs --headed
pwsh -NoProfile -File scripts/test-rust.ps1
npm start
```

Rust 安装脚本及紧接着的 `cargo fetch` 应在同一个 PowerShell 会话运行，以保留隔离工具链的环境设置。如果 Windows 执行策略阻止脚本，请检查脚本和组织策略，不要全局关闭安全控制。

本地操作界面将在专用浏览器窗口打开。关闭窗口，或在启动它的终端按 Ctrl+C，即可正常退出。如果控制器 EXE 正在使用中，请勿覆盖构建或结束无关进程；应正常退出自己的应用后重新构建，或使用另一份源代码目录。

## 不使用真实书籍试用

1. 点击 **“确定／下一步”**，准备新任务。
2. 展开专用会话与自制样本的辅助设置，选择**自制样本**。
3. 选择样本的阅读标签页，核对预览、勾选确认并批准。**批准本身不会开始获取。**
4. 通过另一次操作明确开始，停止后检查保存的图像，再导出。

样本包含自制图形与文字。样本成功不证明当前 Kindle、所有布局或整本书都能正常获取。不要将登录页面作为获取目标。

## 使用 Kindle 网页阅读器

1. 从应用打开专用 Kindle 浏览器。自行在**官方页面**登录并完成额外验证，打开一本书并调整起始位置。
2. 返回应用，选择实际阅读标签页，而不是书架。v0.1.6 打开所选日本、美国或英国地区的 Kindle 网页阅读器。先尝试适用的 Kindle 预设，必要时手动指定阅读区域、书籍标识、位置和下一页按钮。
3. 核对预览中的书籍、区域、方向和位置。批准后，通过另一次操作明确开始。目标不明确、认证状态变化或翻页结果不确定等情况可能使获取停止。
4. 停止后检查采用、排除、顺序、裁剪以及可选的跨页拆分。获取或预览停止后，已经确认保存的图像仍可导出。压缩包验证成功不表示整本书已完整获取。

主要按钮为 **“确定／下一步”“取消／上一步”“结束／重新开始”**。请遵循下一步操作提示；三个阶段不意味着只需点击三次。语言菜单可选择日语、英语或简体中文。当前源代码 CI 已通过公开语言切换检查；历史失败与打包验证范围见[验证记录](validation.md)。

### v0.1.6 地区选择与边距比较

打开专用浏览器前，在 **Kindle 使用地区** 中选择日本、美国或英国。此设置独立于界面语言，每次启动默认为日本。更改地区时先停止获取并关闭专用浏览器，再选择地区、重新选择标签页、预览、确认并单独开始。官方入口确认及匿名边界测试不证明各地区真实书籍兼容性。

在图像检查中选择图像，点击 **检测所选图像的空白**，将白色／黑色边缘候选与原图比较。检查正文、边框和页码后再应用。取消不改变保存状态；仍可手动裁剪或恢复原始尺寸，也可能找不到候选。应用 JPEG 裁剪时按获取时的画质重新压缩。这些新增功能已包含在 v0.1.6 Portable 版本中。[适配器计划](store-adapters.md)中的三家服务仍未支持。

## 图像、保存数据与隐私

v0.1.6 可在预览前选择获取图像格式与 JPEG 画质（1–100）。JPEG 获取时会压缩，裁剪或拆分时也会再次压缩；请检查画质和容量。已获取原图的字节保持不变。检查时可逐张更正为一页或两页并选择顺序，手动裁剪边距，或用“恢复原始尺寸”还原原图。边距候选须比较后明确应用，不会擅自应用。布局判断和遮挡抑制并不完全，请本人检查。

- 标准或2倍渲染密度改变页面的渲染方式，不会恢复原本不存在的细节。**每张图像 16百万像素 / 32 MiB** 是安全上限，不是付费配额。
- 跨页拆分为可选功能。选择右到左或左到右的阅读顺序，并自行检查结果；这不是语义页面识别。排除和裁剪保留原图，不覆盖已有输出文件。
- 除非明确指定其他本地任务位置，开发版的任务数据与专用配置目录位于 `artifacts/mvp-data/`。Portable 构建会在 EXE 旁创建 `runtime/`、`data/` 和 `temp/`。
- **默认开启登录状态保留。** 关闭后使用另一个临时配置目录，正常退出时删除，异常退出可能留下数据。已保存的配置目录以同一台电脑、同一 Windows 用户复用为前提，不能绕过 Amazon 的会话失效或重新认证要求。
- Cookie、配置目录、书名、截图和输出压缩包应保持私密，不要将这些目录附在公开问题报告中。不保证安全擦除，也不保证对管理员或同一 Windows 用户保密。
- 官方阅读、认证通信和初次下载需要联网。本应用没有自建遥测、自动更新检查或自动访问赞助页，但官方服务与 Chromium 可能产生其他请求。这不是离线可用或网络隔离的保证。

请阅读[安全与网络详情](security-and-trust.md)、[验证报告](validation.md)（英语）及[法律注意事项](legal-notes-ja.md)（日语）。不移除 DRM 不代表符合 Amazon 条款或版权要求。本应用为非官方工具，GPLv3 不授予再分发书籍内容的许可。

## 遇到问题时

目标不明确或预览为黑屏时，不要反复开始获取。停止并保留已有图像，按照界面的下一步提示处理。报告问题前请先查看[已知验证失败](validation.md)（英语）；文档本身不会修复这些问题。报告中请移除认证信息、书名、书籍正文和个人路径。

源代码测试、Portable 打包和构建来源证明请参阅[开发说明](development.md)与[发布验证](releasing.md)（英语）。这些是开发流程，不是当前可下载的公开可执行文件，也不证明发布已通过验证。
