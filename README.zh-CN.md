# KindleToZip

在 Windows 上截取 Kindle 网页阅读器中显示的页面，检查 PNG 截图后，按顺序保存为 ZIP / CBZ。

**完全免费、开源 · Windows x64 · 无需注册 KindleToZip 账户 · 无付费 DLC**

> **实验阶段：目前提供源代码，尚无公开的 Portable 可执行文件。**
> 仍有已知测试失败，不是已经验证、开箱即用的正式版本。

**[从源代码开始 · 入门指南](docs/getting-started.zh-CN.md)** · [查看发布情况](https://github.com/zufall-upon/KindleToZip/releases)

## 从阅读器到压缩包的三个阶段

**打开 → 获取 → 检查并保存**

1. **打开。** 在专用浏览器的 Kindle 官方页面自行登录，打开一本书并选择阅读标签页。
2. **获取。** 指定获取区域，检查预览并确认，然后通过另一次操作明确开始获取。
3. **检查并保存。** 停止后检查已保存的图像，调整顺序或裁剪，再导出 ZIP / CBZ。

这是**三个阶段，不是只需点击三次**。请按照界面的“下一步操作”提示，以及 **“确定／下一步”“取消／上一步”“结束／重新开始”** 三个主要按钮操作。

## 主要功能

以下功能已在源代码中实现，但仍受下文已知问题的影响。

- **专用浏览器：** 使用独立于日常浏览器的配置目录，显示 Kindle 网页阅读器。
- **区域选择与预览：** 选择当前显示的阅读区域，在保存前核对内容。
- **页面获取：** 用户明确开始后执行翻页，将显示的页面保存为 PNG 截图。
- **跨页拆分与顺序调整：** 可拆分左右页面、选择阅读方向，并重新排列已获取图像。
- **图像检查：** 保留原图，调整采用或排除状态，并进行非破坏性裁剪。
- **ZIP / CBZ 导出：** 按指定顺序保存采用的 PNG，不覆盖已有输出文件。
- **停止后的检查：** 无需重新获取，即可检查和导出已经确认保存的图像。
- **三种界面语言：** 可在语言菜单选择日语、英语或简体中文。

## 入门与获取方式

**目前没有公开的 Windows Portable 版本可供下载。** 如需体验实验版本，请使用[源代码运行指南](docs/getting-started.zh-CN.md)。需要 **Windows x64、Git、Node.js 22 或更高版本，以及 PowerShell 7**；指南会安装隔离的 Rust 工具链和专用浏览器。

准备完成后，在项目目录运行 `npm start`，即可打开本地操作界面。按照提示启动专用阅读器、预览、获取并保存。如不希望使用真实书籍，可按指南打开自制测试样本。

如果需要无需开发环境的应用，请稍后查看[发布页](https://github.com/zufall-upon/KindleToZip/releases)。存在 Portable 构建脚本，**不代表**已经公开经过验证的可执行文件。

### 常见问题

**KindleToZip 免费吗？需要另行注册账户吗？**

免费且开源，无需 KindleToZip 账户，也无需付费解锁功能。Kindle 官方服务仍需要 Amazon 账户，以及适用的内容购买或订阅。

**在哪里下载 Windows Portable EXE？**

目前尚无公开的可执行文件。可以按指南从源代码运行，或等待正式公开的发布版本。

**它能移除 DRM，或操作 Windows 版 Kindle 桌面应用吗？**

不能。它只截取 Kindle 网页阅读器中显示的内容，不解密电子书文件，不绕过 DRM 或截图限制，也不操作桌面应用。

**能自动按正确顺序保存整本书吗？**

不保证。请自行检查获取范围、页面顺序、跨页拆分和停止位置。ZIP 验证成功不等于整本书已完整获取。

**可以切换应用语言吗？**

可以。在语言菜单选择日语、英语或简体中文。语言支持已经实现，但验证报告中仍包含语言切换流程的测试失败。

## 安全与隐私

- **只在官方页面登录。** 本应用没有独立的登录服务器，不会有意读取密码输入框的值，也未实现向应用运营方服务上传 Amazon Cookie 的功能。
- **默认保存登录状态。** 关闭保留登录状态的设置后，会使用另一个临时配置目录。正常退出时删除临时数据，异常退出可能留下文件。
- **不要分享本地数据。** 开发版使用 `artifacts/mvp-data/`；Portable 构建使用 EXE 旁的 `runtime/`、`data/`、`temp/`。其中可能包含 Cookie、历史记录、书籍信息和截图，请勿公开或附在问题报告中。
- **仍会进行网络通信。** 官方阅读与认证服务、浏览器及首次安装需要联网。本应用没有自建遥测、自动更新检查或自动访问赞助页面的功能，但这不表示 Chromium 或官方网站不会产生其他请求。

详情请参阅[认证信息、网络目标与信任边界](docs/security-and-trust.md)（英语）。开源便于审查，**不等于自动保证安全**。本地令牌和 Windows 权限不能保证抵御恶意软件、管理员或以同一 Windows 用户运行的其他进程。

## 限制与法律注意事项

- **已知失败：** 初次公开源代码的 `npm test` 结果为 **125 项通过、12 项失败，约576秒**，其中包含父测试与子测试的失败。Rust、IPC/local-store 和部署检查分别通过。本次文档更新不修复或豁免这些失败。请参阅[验证报告](docs/validation.md)（英语）。
- **兼容性不保证：** 尚未验证干净的 Windows 环境、所有 Kindle 布局、整本书获取、ZIP64 或所有 CBZ 阅读器。当前入口面向日本地区的 Kindle 网页阅读器，其他地区未验证，桌面应用不受支持。
- **图像上限：** 可选择标准或2倍渲染密度，安全上限为**每张 PNG 16百万像素 / 32 MiB**。提高密度无法恢复原始显示中不存在的细节。跨页拆分不是语义页面识别，请检查结果。
- **不移除 DRM，不代表已经获得法律或条款许可。** Amazon 的使用条件将机器人等数据收集、提取工具排除在授予的使用许可之外。自动获取与工具分发仍可能涉及合同和版权问题。仅处理获准截取的内容；GPLv3 不授予书籍使用权，也不允许据此再分发获取的页面。

KindleToZip 是**非官方、独立项目**，与 Amazon 无关联，未获其认可或赞助。Amazon 和 Kindle 是 Amazon.com, Inc. 或其关联公司的商标。本项目不声称已经获得 Amazon 或法律专业人士的批准。使用前请阅读[法律问题与调查范围](docs/legal-notes-ja.md)（日语）。
