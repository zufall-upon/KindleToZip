1. 作業を用意する

「決定・次へ」で新しい1冊の作業を用意します。前回の続きだけ、補助設定から中断データを開けます。

作業先・中断データ・終了

2. 専用ブラウザで本を開く

Linuxでは実Kindleの起動・取得は未対応です。補助操作から自作試料を開いてください。

利用地域を選び、本人がログインして1冊を開きます。本棚タブは閉じなくてかまいません。

表示言語とは別の設定です。地域を変えるには専用ブラウザを閉じ、対象タブの選択・プレビュー・承認をやり直してください。

ログイン状態はEXE横に保存します。同じPC・Windows利用者で再利用でき、再認証が必要な場合もあります。

「決定・次へ」で専用Kindleを開きます。本を開いた後も同じボタンで対象タブの選択へ進みます。

専用セッション・自作試料（補助）

公式画面でログイン・追加認証・1冊選択・開始位置の調整を行ってください。パスワードをこのアプリへ入力しないでください。取得中の操作は別アプリ・通常ブラウザで行ってください。

専用領域にはログイン情報・履歴が残ります。一時領域は通常終了時に削除します。残った領域は下で削除できます。

    3. 指定 → プレビュー → 取り込み

    読書画面のタブを選んで「決定・次へ」。選び直すとプレビューと承認をやり直します。

    タイトル・位置バーのある画面はKindleプリセットでプレビューできます。合わない場合は詳細指定へ。編集はEXE横に保存します。

    プリセットの追加・編集

    4項目とiframeを保存します。既存の編集は初期値で上書きしません。

    取り込みと保存のおすすめ設定

    2倍は高密度で保存します。上限は16メガピクセルです。

    JPEGは取得時に圧縮します。画質を下げると容量は減る傾向がありますが細部は失われます。クロップ・分割時も再圧縮します。原本は保持します。

    設定はジョブに保存されます。変更後はプレビューと承認をやり直します。分割設定はこれから取得する画像に適用し、すでに取得した画像は変えません。

    先に作業と専用ブラウザを用意してください。追従バーの「決定・次へ」から進めます。

    取得中の補助操作（一時停止・安全停止）
    表示の再検査・個別確認（補助）

    自動判定できない場合は、詳細指定で対象を選んでください。

    自動判定できない場合（詳細指定）

    画面の4項目を指定してプレビューします。専用ブラウザの可視UIを使い、指定クリックでページは送りません。CSS・iframeを使う方法はさらに下の詳細設定にあります。

    未指定

    範囲が合わない場合・CSS/iframe設定

    読書枠を変えたときも、本・範囲・方向が正しいことを確認するまでは開始しないでください。

    プレビューはまだありません。表示範囲の画素寸法と保存単位を確認できます。

    最後の確定画像と再開位置

    現在位置が最後の画像の直後か、本人が照合してください。違う場合は公式画面で手動調整し、再プレビューしてください。

    プレビューを見てから開始

    終端候補・白紙・重複・ログアウト・不明な送りで停止します。取得範囲は目視確認してください。

    4. 画像を点検・並べ替え・クロップ

    画像カードの「前へ」「後へ」で出力順を変更できます。「除外」しても原本は消えません。画像ごとに1枚または左右2枚と読み順を修正できます。判定は目視で確かめてください。

    画像番号を指定して順序・採用を変更

    選択画像の非破壊クロップ

    画像カードで選ぶか画像IDを入力し、白・黒の端余白の候補を検出できます。内容認識ではありません。原本と見比べ、本文・枠・ページ番号が残る場合だけ適用してください。候補だけでは保存状態は変わりません。

    点検後は「決定・次へ」でZIP保存へ進みます。

    5. ZIPを保存

    初期保存先はこの作業のフォルダです。既存ファイルは上書きしません。

    ダイアログで選ぶだけでは保存・取得を開始しません。手入力も利用できます。

    停止・プレビュー失敗後も、保存済みの採用画像をZIPにできます。
